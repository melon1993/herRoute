# 她出行 HerRoute

> 基于百度地图LBS的家庭女性智能出行规划助手

## 项目简介

「她出行」是一个专为承担家庭多重角色的女性设计的智能出行规划助手。针对职场妈妈每天接送孩子、通勤、采购、就医等多目标出行难题，通过百度地图途经点智能路线规划API自动排序优化，结合时间窗约束生成最优行程时间轴。

## 核心功能

- **智能路线规划**：多途经点智能排序，结合时间窗约束生成最优出行方案
- **动态行程调整**：计划变化时实时重新规划，最小化变更影响
- **习惯学习与推荐**：记录出行模式，主动提供智能建议
- **家庭协同出行**：合并家人路线，智能分工协作

## 技术Demo

打开 `index.html` 即可体验完整功能：

1. 双击 `index.html` 用浏览器打开
2. 点击「加载示例」查看完整演示
3. 或使用快捷按钮 / 手动输入添加行程
4. 点击「智能规划最优路线」查看优化结果

### 技术栈

- 纯前端实现，零依赖
- Canvas 地图渲染
- 内置 TSP 近似算法（贪心最近邻 + 时间窗约束）
- 可选接入百度地图真实API（需AK）

## 百度地图API接入

本Demo默认使用内置算法演示。如需调用真实百度地图API：

1. 访问 [lbs.baidu.com](https://lbs.baidu.com) 注册账号
2. 创建应用获取 AK（Access Key）
3. 在Demo中输入AK即可切换到真实API模式

详细步骤见 [docs/API-Key获取指南.md](./docs/API-Key获取指南.md)
