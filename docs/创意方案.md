## 「她出行 HerRoute」— 家庭女性智能出行管家

### 一、创意背景与痛点分析

在中国，大量女性同时承担职场、育儿和家务三重角色。她们每天的出行不是简单的A到B，而是由多个任务节点交织而成的复杂网络：早上送孩子上学、赶去公司打卡、中午抽空去超市采购、下午接孩子放学、傍晚带老人去医院复查、晚上回家做饭……

这些出行任务有几个鲜明的特征：

**多目标、强约束。** 每个任务都有时间窗口（学校8点前送到、公司9点打卡、医院预约14:30），且任务之间存在先后依赖关系（先送孩子才能去上班）。传统导航只能解决"两点之间怎么走"，无法处理"一天之内十几个点怎么串"的问题。

**动态变化频繁。** 孩子学校临时通知提前放学、超市今天特价需要提前去买、老人突然需要去医院——计划随时被打乱，而重新规划整条路线的认知负担很高。

**路线重复但低效。** 很多女性每天走相似的路线，但由于缺乏全局优化，往往存在不必要的绕路。长期累积下来，浪费的时间和精力相当可观。

目前市面上的导航产品（百度地图、高德地图等）都提供了优秀的点对点导航和基础的多途经点功能，但缺少一个专门为"家庭事务出行"这个场景做深度优化的产品层。这正是「她出行」要填补的空白。

---

### 二、产品定位

「她出行」是一个基于百度地图LBS能力的智能出行规划助手，专门为承担家庭多重角色的女性设计。它不是一个独立的导航应用，而是一个**智能出行规划层**——理解用户一天的任务清单，结合百度地图的路线规划、实时路况、POI搜索等能力，自动生成最优的出行方案，并在计划变化时动态调整。

**一句话描述：** 告诉她今天要去哪里，她来安排怎么走最省心。

---

### 三、核心功能设计

#### 3.1 智能日程路线规划（核心卖点）

用户以自然语言或结构化方式输入一天的待办事项，系统自动生成最优出行路线。

**输入方式：**
- 语音/文字输入："早上8点送朵朵去实验小学，然后我去公司，中午要去永辉超市买菜，下午3点接朵朵放学，4点半带妈去市医院复查"
- 结构化输入：在时间轴上添加任务卡片（地点 + 时间窗口 + 优先级）

**智能优化：**
- 调用百度地图**途经点智能路线规划API**（intelligent_plan=1），综合考虑路况、限行、绕路成本，自动排列最优途经顺序
- 结合**时间窗约束**进行调度优化：确保每个任务在允许的时间范围内完成
- 输出完整的**时间轴行程表**：每个节点的出发时间、预计到达时间、路程耗时、缓冲时间

**示例输出：**
```
07:20  从家出发 → 实验小学（送朵朵）
       路程 12分钟 | 路况畅通
07:35  到达学校，停留5分钟
07:40  学校 → 公司
       路程 18分钟 | 路况畅通
08:00  到达公司 ✓ （提前0分钟）
...
12:15  公司 → 永辉超市（万达店）
       路程 8分钟 | 轻度拥堵
12:25  购物约20分钟
12:50  超市 → 公司
       路程 8分钟
13:00  回到公司 ✓
...
```

#### 3.2 动态行程调整

当计划发生变化时（新增任务、取消任务、时间变更、突发拥堵），系统实时重新规划。

**触发场景：**
- 用户主动修改："学校通知今天提前到2点半放学"
- 系统检测到异常："前方路段发生事故，预计拥堵30分钟，建议调整行程"
- 智能提醒："永辉超市今天鸡蛋特价，是否加入今天的采购清单？"

**调整策略：**
- 最小化变更原则：尽量只调整受影响的后续行程，不推翻整个计划
- 提供多个备选方案，让用户选择
- 如果某个任务因时间冲突无法完成，提前预警并建议替代方案（如换一家更近的超市）

#### 3.3 习惯学习与智能推荐

系统记录用户的历史出行模式，逐步学习并主动提供建议。

**学习能力：**
- 识别常去地点（学校、公司、超市、医院、父母家等）
- 学习出行时间规律（每周二四去健身房、每月15号去银行）
- 记录偏好（喜欢走哪条路、偏好哪个超市、通常购物花多长时间）

**智能推荐：**
- "明天是周一，需要我帮你规划送朵朵上学和上班的路线吗？"
- "你通常每周三下午去接妈妈做理疗，需要加入明天的行程吗？"
- "根据你过去的记录，周末采购通常需要40分钟，我已为明天的超市行程预留了时间"

#### 3.4 家庭协同出行

支持家庭成员之间的行程共享和协调。

**功能：**
- 生成行程分享卡片，发送给配偶/家人
- 多人行程合并优化："老公下午也去医院附近办事，可以顺路接妈回家"
- 紧急通知："我这边堵车了，接孩子可能要晚10分钟，你能帮忙吗？"

#### 4.2 核心API调用方案

**（1）途经点智能路线规划**

这是产品的核心API。百度地图提供了 `intelligent_plan` 参数，传入多个途经点后，API会综合考虑路况、交规限行、途经点相对位置及绕路成本，自动调整顺序给出最优路线。

```
GET https://api.map.baidu.com/direction/v2/driving
参数：
  origin=39.915,116.404        // 起点
  destination=39.975,116.424   // 终点
  waypoints=39.935,116.414|39.955,116.434  // 途经点
  intelligent_plan=1           // 启用智能排序
  ak=YOUR_AK                   // 开发者密钥
```

**（2）地理编码服务**

将用户输入的自然语言地址转换为坐标：

```
GET https://api.map.baidu.com/geocoding/v3/
参数：
  address=北京市海淀区实验小学
  city=北京
  ak=YOUR_AK
```

**（3）地点搜索（POI）**

当用户说"去超市买菜"但未指定具体超市时，搜索附近超市：

```
GET https://api.map.baidu.com/place/v2/search
参数：
  query=超市
  location=39.915,116.404
  radius=2000
  ak=YOUR_AK
```

**（4）实时路况**

获取路线的实时交通状况，用于动态调整：

```
GET https://api.map.baidu.com/traffic/v1/bound
参数：
  bounds=39.915,116.404;39.975,116.424
  ak=YOUR_AK
```

#### 4.3 核心算法：时间窗约束下的路线优化

这是一个带时间窗的车辆路径问题（VRPTW）的简化版本。我们的求解策略：

1. **初始排序：** 调用百度智能路线规划API获取基础最优路径
2. **时间窗校验：** 检查每个节点是否满足时间约束
3. **局部调整：** 对不满足约束的节点进行插入/交换操作
4. **迭代优化：** 重复2-3步直到所有约束满足或达到迭代上限

伪代码：

```python
def optimize_route(tasks, start_time):
    # tasks: [{location, time_window_start, time_window_end, duration, priority}]
    
    # Step 1: 百度API智能排序
    route = baidu_intelligent_plan(tasks)
    
    # Step 2: 时间窗校验
    schedule = calculate_schedule(route, start_time)
    violations = find_time_violations(schedule)
    
    # Step 3: 迭代修复
    while violations and iterations < max_iter:
        # 尝试交换违反约束的节点与相邻节点
        route = try_swap(route, violations)
        # 尝试将高优先级任务提前
        route = prioritize_tasks(route)
        schedule = calculate_schedule(route, start_time)
        violations = find_time_violations(schedule)
    
    return schedule
```

### 五、产品原型交互流程

**场景：李婷的一天**

李婷，35岁，互联网公司产品经理，6岁孩子的妈妈。

**Step 1 - 输入任务：**
早上7点，李婷打开「她出行」，语音输入：
"今天要先送朵朵去学校，8点半之前到。然后我去公司，10点有个会。中午要去永辉买菜，下午3点接朵朵，4点带妈去眼科医院。"

**Step 2 - 智能规划：**
系统在3秒内生成完整的出行时间轴，在地图上标注所有节点和路线。

**Step 3 - 确认出发：**
李婷浏览行程，确认无误后点击"开始今天"。系统进入导航模式，在每个节点自动切换导航目标。

**Step 4 - 动态调整：**
上午11点，系统推送："朵朵老师发消息说今天2点半放学（比平时早30分钟），已自动调整下午行程，接完朵朵再去医院，整体时间不受影响。"

**Step 5 - 行程回顾：**
晚上，系统生成今日出行报告：总里程28公里，相比无优化路线节省了约6公里和35分钟。

### 六、商业模式

#### 6.1 免费增值模式

**免费版：** 每日最多规划5个途经点的路线，基础智能排序功能。

**会员版（12元/月）：** 无限途经点、动态调整、习惯学习、家庭协同、出行报告。

#### 6.2 本地生活合作

基于用户的出行路线和POI搜索，与周边商户合作：
- 超市特价提醒（基于用户常去的超市）
- 医院/诊所预约提醒
- 教育机构周边停车推荐

#### 6.3 数据价值（合规前提）

在用户授权和匿名化前提下，为城市规划部门提供"家庭出行热力图"，帮助优化学校周边交通、社区商业配套等。

**核心差异化：** 我们不是做一个新的导航App，而是在百度地图的LBS能力之上，构建一个理解"家庭事务出行"这个独特场景的智能规划层。

### 八、社会价值

**时间价值：** 据估算，一个典型职场妈妈每天在出行上花费约2-3小时。通过智能路线优化，平均可节省15-25%的出行时间，即每天节省20-40分钟。

**心理健康：** 减少"今天事情太多跑不过来"的焦虑感，让家庭女性对自己的日程有更强的掌控感。

**社会意义：** 关注家庭女性的隐形劳动负担，用技术手段让被忽视的"家庭出行规划"工作得到支持和认可。
