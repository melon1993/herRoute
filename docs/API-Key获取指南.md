# 百度地图 API Key 获取与配置指南

## 一、注册百度地图开放平台账号

1. 访问 [https://lbs.baidu.com](https://lbs.baidu.com)
2. 点击右上角"登录/注册"
3. 使用百度账号登录（没有则注册一个）
4. 登录后进入"控制台"

## 二、创建应用获取 AK

1. 在控制台左侧菜单选择"应用管理" → "我的应用"
2. 点击"创建应用"
3. 填写应用信息：
   - **应用名称**：她出行 HerRoute（或自定义）
   - **应用类型**：浏览器端（JavaScript API）
   - **Referer白名单**：填写 `*`（开发测试用）或填写你的域名
   - **启用服务**：勾选以下服务
     - JavaScript API GL
     - 地理编码
     - 驾车路线规划
4. 点击"提交"
5. 创建成功后会显示 **AK（Access Key）**，复制保存

## 三、在 Demo 中使用 AK

1. 打开 `她出行-HerRoute-技术Demo.html`
2. 页面加载后会显示 API Key 输入框
3. 将复制的 AK 粘贴到输入框
4. 点击"确认加载"
5. 地图将自动加载，可以开始使用

## 四、Demo 功能说明

### 核心功能

1. **添加途经点**
   - 输入任务名称（如：送孩子上学）
   - 输入地址（如：北京市海淀区实验小学）
   - 选择任务类型（学校/工作/购物/医院/家/其他）
   - 设置时间范围
   - 点击"添加"

2. **智能路线规划**
   - 添加至少2个途经点后
   - 点击"智能规划路线"
   - Demo 将调用百度地图 API：
     - 地理编码 API：将地址转换为经纬度
     - 驾车路线规划 API：生成最优路线（启用智能途经点排序）
   - 地图上会显示：
     - 各途经点标记（带编号和名称）
     - 优化后的路线（紫色实线）
   - 左侧面板会显示：
     - 路线统计（总里程、总耗时、智能优化节省比例）
     - 智能行程时间轴（带路况标签）

3. **加载示例行程**
   - 点击顶部"加载示例行程"按钮
   - 自动加载预设的6个途经点（李婷的一天）
   - 自动调用 API 生成路线

### API 调用说明

Demo 调用以下百度地图 API：

1. **JavaScript API GL**
   - 用途：地图展示、标记、路线绘制
   - 文档：https://lbs.baidu.com/index.php?title=jspopularGL

2. **地理编码 API**
   - 用途：将地址转换为经纬度坐标
   - 文档：https://lbs.baidu.com/index.php?title=webapi/guide/webservice-geocoding

3. **驾车路线规划 API**
   - 用途：生成最优驾车路线
   - 参数：`intelligent_plan=1` 启用智能途经点排序
   - 文档：https://lbs.baidu.com/index.php?title=webapi/directionlite-v1

### 容错机制

- 如果 API Key 无效或网络请求失败
- Demo 会自动使用模拟数据演示
- 地图上会显示虚线连接各点
- 左侧会显示模拟的统计数据和时间轴
- 确保即使 API 不可用也能展示完整功能

## 五、注意事项

1. **AK 安全**
   - AK 仅保存在浏览器内存中
   - 不会上传到任何服务器
   - 刷新页面后需要重新输入

2. **API 配额**
   - 百度地图 API 有每日调用配额
   - 个人认证用户配额较高
   - 开发测试阶段通常够用

3. **浏览器兼容性**
   - 推荐使用 Chrome、Firefox、Edge
   - 需要支持 ES6+ 语法

4. **网络要求**
   - 需要能访问百度地图 API 服务器
   - 建议在网络稳定的环境下使用

## 六、常见问题

**Q: 地图加载失败？**
A: 检查 AK 是否正确，应用类型是否选择"浏览器端"

**Q: 路线规划失败？**
A: 检查是否启用了"驾车路线规划"服务，或网络是否正常

**Q: 地理编码失败？**
A: 地址可能无法识别，Demo 会使用随机坐标作为备选

**Q: 如何获取更高配额？**
A: 在百度地图开放平台完成企业认证，或申请配额提升

## 七、进阶使用

### 自定义地图样式

在 `initMap()` 函数中修改：
```javascript
map.setMapStyleV2({ styleId: '你的样式ID' });
```

### 添加更多途经点

可以添加任意数量的途经点，API 会自动优化排序。

### 调整路线偏好

在 API 调用中添加参数：
- `tactics=0`：智能推荐
- `tactics=1`：避免拥堵
- `tactics=2`：最短距离
- `tactics=3`：最短时间

### 集成到实际项目

1. 将 HTML 文件部署到你的服务器
2. 在服务器端管理 AK（不要暴露在前端）
3. 添加用户认证和权限管理
4. 实现数据持久化（保存用户的途经点）
